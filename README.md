# **BreastCancerML**
**Fecha:** 09/07/2024  

---

## Descripción

Este proyecto fue llevado a cabo en 2023 como proyecto final de la asignatura Fisica Computazionale Avanzata impartida en la Universidad de Salerno. El objetivo principal es aprender las relaciones entre datos biomédicos de pacientes con cáncer de mama para poder ofrecer una estimación de la esperanza de vida. Además, se pretende comparar un modelo de red neuronal densa programado sin el uso de librerías con un modelo que utiliza Keras de Tensorflow.

---

## Dataset

- Link: https://www.kaggle.com/datasets/reihanenamdari/breast-cancer  
- Contiene datos de **4024 pacientes** diagnosticados con cáncer de mama, obtenidos del programa **SEER (Surveillance, Epidemiology, and End Results)** del *National Cancer Institute* de Estados Unidos.  
- Incluye parámetros biomédicos como edad, tamaño del tumor, estadios T y N, estado de receptores hormonales (ER/PR), número de ganglios afectados, meses de supervivencia y estado vital.
